# Receipt Scanning Application

This application scans receipts, extracts information using OCR, and stores it in a database. It also allows exporting the data to an Excel sheet.

## Project Structure

- `backend/`: Contains the FastAPI backend application.
- `frontend/`: Contains the frontend application.
- `database/`: Contains the database files.
- `scripts/`: Contains utility scripts.
- `tests/`: Contains the test suite.
